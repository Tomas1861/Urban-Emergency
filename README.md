# Urban-Emergency · 演安智策

面向复兴岛大型活动的应急预案智能生成、人机协同处置的产教研一体化平台。

Ontology（业务本体）+ Agentic（智能体驱动）架构：把活动现场的区域、通道、设施、岗位、人员和资源，以及事件、预案、任务、授权和执行证据，组织为统一、持续更新的业务对象，供预案生成、现场处置、教学实训共用同一套事实。

## 目录结构

- `backend/` —— FastAPI + SQLAlchemy 后端：活动/事件/预案/任务模型，态势研判、方案编排等 Agent
- `frontend/` —— Vue3 + Element Plus 业务前端：活动管理、事件处置六步向导（事件确认→知识检索→预案生成→任务分解→执行跟踪→复盘报告）
- `admin/` —— Vue3 + Element Plus 管理后台
